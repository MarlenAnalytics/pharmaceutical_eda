# Pharmaceutical EDA
This project is an Exploratory Data Analysis (EDA) of a pharmaceutical dataset. It uses Python libraries like pandas, matplotlib, and seaborn to explore trends, detect patterns, and understand relationships within the data.

## Project Goals
- Perform data preparation

- Visualize distributions and correlations

- Identify trends and insights

- Provide statistical summaries

## Database Structure
The pharmaceutical dataset contains the following important columns:

- `LOCATION:` country code
- `TIME:` date (year)
- `PC_HEALTHXP:` percent of health spending
- `PC_GDP:` percent of GDP
- `USD_CAP:` US dollars per capita
- `TOTAL_SPEND:` total spending (millions)

## Results
The notebook contains several visualizations and summary statistics that highlight:

- Distribution of features

- Correlation scatter plots

- Any patterns found during exploration

The pharmaceutical dataset was obtained on datahub.io at the following link:
